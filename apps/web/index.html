VoC Radar

VoC Radar는 App Store 공개 리뷰를 반복 이슈와 근거 리뷰로 정리해 제품팀이 고객의 목소리를 빠르게 확인하도록 돕는 공개 리뷰 인텔리전스 도구입니다. 앱 이름, App Store URL 또는 숫자 ID로 앱을 찾고, 게시된 분석 리포트를 로그인 없이 읽을 수 있습니다.

리포트에서 확인할 수 있는 내용

개요는 분석 기간의 리뷰 수, 평균 평점, 낮은 평점 비율과 마지막 분석 시각을 보여 줍니다. 이슈 목록은 비슷한 불만과 요청을 하나의 주제로 묶고 심각도, 발생량, 변화율, 요약과 권장 대응을 제공합니다. 각 이슈의 근거 화면에서는 실제 공개 리뷰를 함께 확인할 수 있어 자동 분류 결과를 원문과 대조할 수 있습니다.

이 자료는 제품 관리자, 고객경험 담당자, QA 엔지니어와 운영 담당자가 반복되는 버그, 계정·결제 문제, 정책 불만, 사용성 요청을 탐색할 때 유용합니다. 공개 리포트는 이미 완료되어 게시된 분석 스냅샷이며, 새로운 분석이나 새로고침 요청에는 로그인이 필요합니다.

데이터 범위와 해석

VoC Radar는 App Store에 공개된 리뷰만 다루므로 전체 사용자 의견이나 앱의 현재 품질을 완전히 대표하지 않습니다. 자동 분석은 비슷한 표현을 묶고 우선순위를 보조하지만 오류가 있을 수 있습니다. 중요한 판단에는 이슈 수치만 사용하지 말고 근거 리뷰, 분석 기간과 마지막 게시 시각을 함께 확인하세요. 공개 API는 조회 전용이며 인증이 필요한 사용자 작업과 내부 파이프라인은 공개 문서 범위에서 제외됩니다.
